## 개요

`09개발메모.md`가 한 시점의 스냅샷 메모라면, 이 문서는 세션마다 실제로 한 작업을 **날짜별·시간순(최신이 위)** 으로 누적 기록하는 개발 로그다. `/개발로그` 스킬이 이 파일을 관리한다.

- **HP 표시 버그 수정**: `server/src/socketHandlers.ts`의 `emitState()`에서 `state:players` 이벤트를 `state:phase_changed`보다 먼저 보내도록 순서 변경. 라운드 전환 시 플레이어 화면이 최신 HP를 못 읽고 잠깐 "HP 0"으로 표시되던 레이스 컨디션 해결.
  - 검증: `npx tsc --noEmit` 통과, 유닛 테스트 9/9 통과, 브라우저에서 8명 실제 플레이로 재현 안 됨을 확인.
- **git 첫 커밋 & GitHub 푸시**: 로컬 브랜치를 `master` → `main`으로 정리하고 `node_modules` 제외한 코드+문서+옵시디언 vault 전체(34개 파일) 커밋. `origin`을 `https://github.com/Yoochoyoon/-`로 연결해 푸시 완료.
- **Render.com 배포는 보류**: 사용자가 직접 진행하기 어려운 상황이라 다음 작업으로 순서 변경.
- **2차 작업 착수 — 특수 능력 7종 구현**: `02역할.md`·`03라운드진행.md`·`04핵심메커니즘.md` 기준으로 보스(긴급 처형)·경호원(육탄방어/충성심서약)·스파이(교란작전)·배신자(흑막의미소) 능력과 1라운드 정찰 라운드(스파이 서로 정체 확인, 공격 불가)를 구현 중. (진행 상황은 다음 로그 항목에서 이어짐)
- **개발로그 문서 & `/개발로그` 스킬 신설**: 이 파일(`10개발로그.md`)과 `.claude/skills/개발로그/SKILL.md`를 새로 만들었다. 윈도우는 폴더명에 `:`을 못 써서 사용자가 요청한 `/개발:로그` 대신 `/개발로그`로 이름 지음.
- **특수 능력 7종 구현 완료**: `types.ts`에 `NightAction`/`PlayerAbilityState` 도입, `resolveRound.ts`의 밤 해석 로직을 "교란(침묵) → 방어/보호 → 공격 합산 → 회복" 4단계 파이프라인으로 재작성, `socketHandlers.ts`에 1라운드 정찰(스파이 상호 정체 공개, 전투 없음)과 2라운드부터의 `player:night_options`/`player:submit_night_action` 배선 추가, `player.js`/`player.html`에 행동 선택(기본공격 vs 특수능력) UI 추가. 배신자 "이중 스파이" 패시브와 스파이 "암둠의 공모"(실시간 합공 신호 UI)는 대응하는 메커니즘이 없거나 별도 UI 설계가 필요해 이번 스코프에서 보류.
  - 검증: 유닛 테스트 16개 통과(능력별 개별 케이스 포함), `npx tsc --noEmit` 통과, `socket.io-client`로 실제 서버에 8명+진행자를 접속시켜 1라운드 정찰→2라운드 육탄방어(흡수) 시나리오를 소켓 통신으로 end-to-end 확인. 브라우저로 직접 눈으로 보는 테스트는 아직 안 함.
- **첫판 힌트 툴팁 구현**: `07룰복잡도온보딩.md` 기준으로 1~2라운드에만 페이즈별 짧은 안내문을 보여주고 3라운드부터 자동으로 사라지게 함(서버/데이터 변경 없이 `player.js`에서 이미 받고 있던 라운드 번호만으로 클라이언트에서 판단). 남은 2차 기능 중 서버 변경이 전혀 필요 없는 가장 단순한 항목이라 이걸 먼저 골랐다. 참고로 "닉네임 중복 방지"는 확인해보니 이미 기존 코드에 구현되어 있었음(메모가 안 맞았던 것) — `09개발메모.md` 목록에서 정정.
- **브라우저 8명 실전 테스트로 특수 능력 + 힌트 검증**: `npm run dev` 후 크롬 탭 10개(진행자/TV/플레이어 8)로 1라운드 정찰 → 2라운드(보스 긴급처형 실제 클릭으로 사용해 스파이에게 2배 데미지 확인, 경호원 충성심서약으로 공격 무효화 확인) → 3라운드(힌트 소멸, 소진된 능력이 목록에서 빠짐)까지 눈으로 직접 확인. 이 과정에서 `player.js`의 `renderActionChoices()`가 특수 능력이 하나도 없을 때 컨테이너를 숨기기만 하고 내부 `<li>`를 지우지 않던 사소한 버그(사용자에게는 안 보이지만 DOM에 잔재가 남는 문제)를 발견해 수정.
