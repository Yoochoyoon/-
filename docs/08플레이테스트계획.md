## 개요

지인 그룹 기반 소규모 반복 플레이테스트 계획과, 밸런스 판단 기준, 그리고 지금까지의 기획 세션(03~07)에서 누적된 검증 필요 항목을 한데 모았다.

## 결정 사항

* **테스트 방식:** 8명 안팎의 **지인 그룹**으로 **3~5회 반복 플레이**. 비용이 거의 안 들고 피드백 루프가 빠르다는 장점을 살린다.
* **밸런스 판단 기준:** **승리 진영이 특정 한쪽으로 쏠리지 않는 것**을 목표로 한다. 3~5판 반복 후 한 역할/진영이 절반 이상 승리하거나 거의 이기지 못하면 문제로 보고, 데미지 수치나 능력 강도를 조정한다.

## 상세 규칙/수치

**세션마다 기록할 것:**

| 항목 | 확인 방법 |
|---|---|
| 실제 소요시간 | 목표(30~40분)와 비교 |
| 승리 진영 | 라운드마다 누적 기록 → 3~5판 후 분포 확인 |
| 라운드 수 | 몇 라운드에서 끝났는지 |
| 플레이어 피드백 | 간단 설문(어느 역할이 헷갈렸는지/재미없었는지) |

**이전 세션(03~07)에서 누적된 검증 필요 항목 체크리스트:**

1. `03라운드진행.md`: 방어/회복 능력이 몰릴 때 정체 국면이 생기는지
2. `04핵심메커니즘.md`: 스파이 '교란 작전'이 기본 공격까지 막는 것이 과도하게 강력한지
3. `05인원세션타겟층.md`: 인원이 늘어날 때 스파이 합공 데미지 균형이 깨지는지, 인원수별 HP·데미지 수치 조정이 필요한지
4. `06컴포넌트테크구현.md`: 진행자가 역할을 겸직할 때 부담이 큰지
5. `07룰복잡도온보딩.md`: 1~2라운드로 한정한 첫판 힌트가 초보자에게 충분한지

## 밸런스 고려사항 / 트레이드오프

* 정성적 재미(설문) 대신 승률 쏠림을 1차 기준으로 삼으면 판단이 명확해지지만, "이기지는 못해도 재미있었다"는 케이스를 놓칠 수 있다 — 설문 항목에 재미도도 가볍게 포함해 보완한다.
* 지인 그룹 반복 테스트는 빠르지만 표본이 작아 우연에 의한 결과일 수 있다 — 3~5회 안에서 극단적인 쏠림(예: 5판 중 4판 이상)만 조정 신호로 삼고, 사소한 편차는 무시한다.
