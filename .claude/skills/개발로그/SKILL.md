# 개발로그 스킬

`docs/10개발로그.md`에 최근 작업 내용을 날짜별(최신이 위)로 기록한다.

## 절차

1. `docs/10개발로그.md`를 읽는다. 없으면 상단에 짧은 개요 한 줄과 함께 새로 만든다.
2. 이번 세션에서 실제로 완료한 작업을 파악한다 — `git log --oneline -10`, `git diff`, 그리고 지금까지의 대화 맥락을 근거로 삼는다. 코드를 그대로 옮겨 적지 말고 **무엇을/왜 했는지** 한두 줄로 요약한다.
3. 오늘 날짜(`YYYY-MM-DD`, 한국 시간 기준) 섹션이 이미 파일에 있으면 그 섹션 안에 새 항목을 이어서 추가하고, 없으면 파일 맨 위(개요 다음)에 새 날짜 섹션(`## YYYY-MM-DD`)을 만든다. 항상 최신 날짜가 위로 오게 유지한다.
4. 각 항목은 굵게 강조한 짧은 제목 + 한두 문장 설명 형식을 따른다(기존 항목 스타일 참고). 버그 수정이면 원인과 해결 방법을, 기능 구현이면 무엇이 가능해졌는지를 적는다.
5. **완료된 작업만** 기록한다. 진행 중이거나 계획만 있는 항목(TODO)은 적지 않는다 — 그런 항목은 `09개발메모.md`의 "다음에 할 일"에 둔다.
6. 기존에 적힌 항목은 절대 수정·삭제하지 않는다. 항상 새 항목을 덧붙이기만 한다.
7. 다 쓰고 나면 사용자에게 어떤 항목을 추가했는지 한 줄로 요약해 보고한다.
